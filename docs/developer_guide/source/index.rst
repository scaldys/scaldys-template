Welcome to scaldys-template's Developer Guide!
===============================================

``scaldys-template`` is a production-ready Python project scaffold.  It gives
you a fully wired starting point — lifecycle management, structured logging,
cross-platform path resolution, persisted settings, an async processing
pipeline, and a complete CI/CD setup — so you can focus on writing your
application instead of the infrastructure around it.

This guide is written for developers who maintain or evolve the template
itself.  If you are building a *new project* on top of it, refer to the
project's user manual (``docs/manual/``) instead.

Start with :ref:`overview` for a high-level picture of what the template
provides, then move to :ref:`architecture` to understand how the pieces fit
together.
